## About This Repository

This repository documents my work throughout DESN368 and my introduction to building for the web with HTML and CSS.

Coming from a background in making, sewing, writing, and design, I approached web development the same way I approach any creative project: start with an idea, experiment a little, make a mess, learn something new, and keep refining until everything comes together. Throughout the quarter, I learned how design decisions become code and how structure, typography, color, and responsiveness work together to create a better user experience.

The projects in this portfolio reflect both technical growth and creative exploration—from recipe pages and tribute sites to interactive storytelling and branded landing pages.

## Design Direction

For my portfolio, I created a visual style inspired by sketchbooks, field journals, coffee-stained notebooks, and creative workspaces that always seem to have one project too many happening at once.

I wanted the site to feel personal and handmade while still being organized and easy to navigate. The warm colors, handwritten accents, and textured design elements reflect who I am as a maker and storyteller, while the clean layouts keep the focus on the work itself.

## Featured Projects

### The Recipe

A recipe website created while learning the foundations of HTML and CSS. This project introduced semantic structure, images, links, and styling while reinforcing the importance of clear organization and readable content.

### Tribute Site

A responsive tribute page celebrating Lucille Ball. The project focused on visual hierarchy, typography, and creating an engaging experience that balanced historical information with personality.

### Field Guide

An interactive storytelling project that combines humor, illustration, and responsive design. Inspired by real-life adventures and everyday chaos, this project explored how narrative and design can work together to create an immersive experience.

### Product Landing Page

A branded landing page promoting a fictional menopause survival kit. Designed with equal parts empathy and humor, the project emphasized user experience, visual hierarchy, and persuasive design principles.
